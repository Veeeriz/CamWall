# CamWall

A camera wall for Apple TV, built for [Frigate NVR](https://frigate.video) and plain RTSP cameras.

This repository holds CamWall's public documentation, privacy policy and issue tracker. The app's source code is not published here.

## Privacy in one line

CamWall collects no data. Everything stays on your Apple TV and goes only to the servers and cameras you add. See the [privacy policy](https://veeeriz.github.io/CamWall/privacy/).
