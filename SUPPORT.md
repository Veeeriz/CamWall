# Getting help with CamWall

- **Guides and FAQ:** the [wiki](https://github.com/veeriz/CamWall/wiki) and the [support page](https://veeriz.github.io/CamWall/support/).
- **Bugs and feature requests:** [open an issue](https://github.com/veeriz/CamWall/issues/new/choose) (needs a GitHub account).
- **Email:** <camwall@veerman.se> — no account needed.

Please don't post passwords, tokens or public addresses of your cameras or Frigate server in issues.
